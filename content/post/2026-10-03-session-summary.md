## 1. 为什么大学儿子国庆仍愿意跨 2000 多公里回家

可能不只是“更恋家”，而是环境变了。

- 过去的大学宿舍、同学关系和校园活动更像独立的小社会，假期留校并不难熬。
- 现在交通更方便，2000 多公里可能通过飞机或高铁就能抵达。
- 独生子女家庭更多，亲子联系也往往更紧密；孩子可能把家视为稳定、放松的补给站。
- 愿意跨很远回家，通常说明他在家里感到被欢迎、放松和牵挂。这不必然代表不独立；有安全感也能让人更有底气向外发展。

## 2. GPT-5.6 Terra 与 Sol 的特点

- `GPT-5.6 Terra`：偏工程执行与稳健性，适合读代码库、拆解任务、修改文件、运行验证和遵守约束；回答风格通常直接务实。
- `GPT-5.6 Sol`：GPT-5.6 系列旗舰档，更适合高难度编码、复杂推理、知识工作、网络安全和科学任务；可使用更高推理强度处理复杂工作，但通常成本和延迟也更高。

选择建议：常规代码、排错和跨文件改动可优先 Terra；需要最高能力、复杂自主工作流或关键难题可选 Sol。

## 3. GPT-5.6 Terra 与 Claude Sonnet 5 的特点

### 定位

- `GPT-5.6 Terra`：GPT-5.6 的均衡档，强调日常工程任务的性价比和稳定执行。
- `Claude Sonnet 5`：Anthropic 的主力均衡模型，强调代理式工作流，例如规划、连续工具调用、浏览器/终端操作和持续推进长任务。

### 使用体感

- Terra 往往更适合明确的工程指令，例如“定位问题、修改代码、运行测试并报告结果”。
- Sonnet 5 往往更适合目标尚不清晰、需要先规划再探索并长期推进的任务。
- 两者都可用于图像理解、工具调用和长上下文；实际效果也会受到推理强度、平台封装和工具权限影响。

### 选择建议

- 常规编程、关注工程执行确定性与成本：优先 Terra。
- 模糊需求、长步骤自主使用工具：优先 Sonnet 5。
- 对关键任务，应用同一真实任务分别测试，通过率、耗时和 token 消耗再决定。

## 4. OpenCode Zen 中适合对话、小问题和查资料的模型

| 场景 | 优先模型 | 原因 |
| --- | --- | --- |
| 普通聊天、概念解释、轻量总结 | `opencode/gemini-3.8-flash` | 快，适合长文本和多模态资料处理。 |
| 中文小问题、高频问答 | `opencode/glm-5.3-flash` 或 `opencode/deepseek-v4-flash` | 中文自然，成本低。 |
| 更自然、严谨的对话与写作 | `opencode/claude-haiku-4-5` | 通常表达清晰、克制。 |
| 长材料梳理、深入分析 | `opencode/gemini-3.1-pro` 或 `opencode/gpt-6-astra` | 更适合复杂上下文和推理。 |
| 免费随手问 | `opencode/nemotron-3.5-lightning-free` 或当前可用的免费模型 | 适合不关键的快速问题。 |

最简选择：

- 默认聊天：`opencode/gemini-3.8-flash`
- 中文高频闲聊：`opencode/glm-5.3-flash`
- 注重质量与表达：`opencode/claude-haiku-4-5`
- 读长文、做分析：`opencode/gemini-3.1-pro`

“查资料”不等于模型天然具备实时检索。涉及新闻、价格、政策、论文或需要可靠引用的信息，应让 agent 实际调用网页搜索/浏览工具，并要求提供来源链接。Zen 模型会更新，应以 TUI 中的 `/models` 为准。
